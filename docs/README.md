# OLS 启动器 0.4.0

**Origin Launch System · 启源**。原青岚启动器更名后的发行版。

Minecraft Java Windows x64 桌面启动器预览版，浅色「晴岚」与暗色「暮色」双主题，原创方块山峦、河流、森林和星空背景。

## 0.4.0 新增

- 游戏数据位置可选：设置中选择目录，复制校验后迁移，旧目录保留备份；重启继续使用新位置。可在首次下载前选择其他盘。
- 本地模组不再阻止开放好友世界，朋友选择已准备实例，按实际JAR摘要校验后加入。需要双方客户端及好友服务端0.4.0。
- 首页使用预渲染景观、减少重复背景绘制和后台刷新，进行滚动采样；开发机未复现用户机器的卡顿。
- 详细步骤、备份清理与限制见 STORAGE_AND_LOCAL_MULTIPLAYER.md。

## 保留的界面功能

- 「关于启源」：产品版本、许可组件、数据和服务说明。
- 页面/弹窗淡入、按钮与卡片反馈，可减少动画并尊重系统偏好。
- 「启动器设置 → 背景与阅读体验」：选择本地背景、遮罩、100%–150% 字号。背景立即保存，其余设置预览后点击保存。默认正文及辅助文字已放大，提高双主题文字对比度。
- 「我的游戏 → 版本资源管理」：快速选择版本，模组/光影/材质包独立分区，各自搜索、筛选、启停和打开文件夹。
- 好友服务断开不阻止普通启动；断线时隐藏过期在线世界。详见 UI_GUIDE.md。

## 启动软件

完整解压 `OLS-Launcher-0.4.0-Windows-x64.zip`，双击文件夹内的 **OLSLauncher.exe**。不要单独移动 EXE，旁边的运行库及 `resources` 文件夹是必需文件。桌面应用自带 Electron 运行时，无需安装 Node.js。

此版本未做代码签名。所有新游戏、资源和配置保存到启动器独立数据目录；路径可在「启动器设置 → 本地存储位置」查看和更改，不自动改动现有 Minecraft 实例。

## 安装与启动 Minecraft

1. 首页点击「安装 Minecraft」，或者进入「我的游戏 → 安装新版本」。
2. 选择官方游戏版本和原版/Fabric。推荐 **Fabric 1.21.1**，它支持自动打开存档并联机。
3. 安装器下载官方客户端、依赖和资源，校验文件，并查找匹配 Java。未找到且开启自动下载时使用 Adoptium Java。
4. 在「启动器设置」填写此启动器的 **Microsoft 公共客户端 Client ID**。正式发布运营者需要自行注册应用并获得 Minecraft API 权限，本包没有借用其他启动器的应用身份。
5. 点击右上角「登录 Minecraft」，获取设备码，在 Microsoft 官方网页完成登录。账号必须拥有 Minecraft Java 版。此预览版不提供离线身份绕过。
6. 选择实例并启动。首次联机前，先在游戏中创建一个世界并正常退出，或使用联机窗口的「导入世界」。

默认加载器支持原版和 Fabric；未集成 Forge、NeoForge、Quilt 或整合包安装器。现代启动参数流程支持 1.13 起的版本，但本轮专门编译的自动联机桥仅适配 1.21.1。

## 识别已有的本地游戏

在「我的游戏 → 识别本地游戏 → 选择文件夹」中选择 .minecraft、PCL 常见版本目录或整合包实例。自动显示版本/加载器、模组名称与版本、世界名和最近游玩时间，以及光影、材质包。扫描只读且无需联网；确认后可复制导入原版/Fabric 的独立实例，校验复用本地游戏文件并补齐依赖。Forge/NeoForge/Quilt 暂支持识别查看。详细步骤与边界见 `LOCAL_IMPORT.md`。

## 模组、光影与材质包

在「发现资源」切换模组/光影/材质包，选择目标实例后搜索、安装。资源来自 Modrinth，按版本和加载器过滤，并解析必要依赖；安装光影会同时准备 Iris。可在「我的游戏 → 版本资源管理」按版本和资源分区启用/停用。文件夹里手动新增但未导入登记的资源，当前不会自动刷新到列表；请使用本地识别复制导入或平台安装。

材质包与光影下载后还需在游戏内的资源包/Iris 设置中选择启用；启动器不会擅自覆盖玩家的画面偏好。游戏运行时禁止修改该实例的资源文件。

## 不连接好友服务器也能启动

普通「启动游戏」不检查启源账号、好友服务器或 SakuraFrp。已安装完成且有匹配 Java、有效的缓存 Minecraft 正版凭证时，可直接启动。首次登录或凭证过期需要连接微软；缺失的依赖仍需要下载。好友服务离线只影响好友状态、世界发布与一键加入，不会终止已启动的本地游戏。

## 好友联机

联机采用“好友关系 → 在线状态 → 世界列表 → 点击加入”，不要求玩家复制邀请码。

1. 运行随附的好友服务端。本机测试需要 Node.js 24，双击服务端包中的 `Start-Server.cmd`。跨网络部署见 `DEPLOYMENT.md`。
2. 你和朋友在「启动器设置 → 好友服务」填写同一服务地址。本机测试默认 `http://127.0.0.1:4589`；跨电脑使用需部署 HTTPS 地址。
3. 在启动器左下角创建/登录启源账号。启源账号管理好友，与 Microsoft 游戏账号是两个账号。
4. 输入朋友的启源账号并发送请求，对方接受后成为好友。
5. 房主在「樱花穿透」绑定 SakuraFrp 访问密钥，进入「好友联机 → 开放我的世界」。
6. 自动模式：选择 **Fabric 1.21.1**、已有存档和可用节点。启动器安装桥接组件、启动游戏、打开存档、开放 LAN、配置 TCP 隧道并启动官方 frpc。
7. 朋友看到世界后点击「加入世界」。启动器准备独立的匹配实例及通过启源安装的模组，再自动连接。

其他版本可使用「连接已开放的 LAN」模式：先在游戏里对局域网开放，填写游戏显示的端口。退出世界、游戏或停止联机后停止穿透，并撤下好友世界。

好友状态每 15 秒同步；异常断线超过 45 秒会变为离线并隐藏世界。好友服务只控制世界信息可见性，不是 Minecraft 网络层白名单；请仅用于可信朋友间的私人联机。本地模组不会自动上传或分发，但允许房主开放世界；好友可选择相同模组的本地实例，校验后加入。私人配置需要双方自行准备。

## SakuraFrp 账号与签到

- 在应用内查看账户等级、带宽、剩余流量、今日用量、流量包和隧道。
- 可绑定/退出账号，查看隧道状态，并确认删除指定隧道。
- 「官方账户管理」在应用内独立的官方网页窗口打开，可处理官网支持的账户操作。
- 「签到领流量」一键打开应用内官方签到页。当前官方开放 API 没有公布签到提交接口，因此不是后台自动签到：若要求网页登录或人机验证，需自行完成。关闭窗口后会重新查询真实签到状态与流量。
- 首版不自动处理要求额外访问认证的节点，这类节点在列表中不可选择。
