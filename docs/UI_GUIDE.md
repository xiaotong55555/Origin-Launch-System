# OLS 0.4.0 使用说明

## 关于页面与动画

侧栏「关于启源」显示软件全称、版本、组件及许可、账号和数据用途、官方站点入口。完整第三方许可文件在软件根目录 THIRD-PARTY-LICENSES.txt。

增加页面、弹窗淡入与按钮/卡片悬浮反馈。「启动器设置 → 背景与阅读体验 → 减少动画」关闭这些效果；系统开启减少动态效果时同样生效，无需额外设置。没有持续播放的全屏动画背景。

## 背景与阅读

1. 进入「启动器设置 → 背景与阅读体验」。
2. 点击「选择背景图片」，选择本地 PNG、JPEG 或 WebP 静态图片，最大24MB。图片会重编码并保存本地副本，不改动原图，原图移动后仍可使用。超大尺寸或解码失败会提示错误。
3. 遮罩范围35%–90%，默认75%。越高越淡化背景。背景显示在内容区域，侧栏/标题栏/卡片保留可读底色。
4. 默认文字已放大并提升弱文字对比度；可选100%、115%、130%、150%。设置页可预览变化。
5. 图片选择/恢复立即保存；遮罩、字号、减少动画和主题需要点击页底「保存设置」。离开设置页会恢复未保存的外观草稿。
6. 「恢复默认背景」删除启动器的图片副本，恢复晴岚/暮色默认景观。

150%大字或较小窗口可能需要更多纵向滚动；侧栏也可以滚动。无需以降低系统分辨率换取可读性。

## 分版本、分资源管理

「我的游戏」选中版本后，在「版本资源管理」下拉框可快捷切换其他版本。模组、光影、材质包分成三个独立分区，每区显示各自数量，不混排。搜索名称/文件名/模组ID，或筛选已启用和已停用；启停开关只修改所选版本的真实文件，不影响另一个版本。

「添加模组/光影/材质包」会打开对应发现分类，并沿用所选安装目标；「打开…文件夹」直接打开当前版本对应目录。退出游戏和等待文件任务结束后再启停，避免边运行边改文件。停用使用 .disabled 后缀，可恢复，不删除资源。光影与材质包的游戏内具体选用仍由 Minecraft/Iris 设置决定。

列表管理通过平台安装或本地复制导入登记的资源。手动在文件夹放入新文件不会自动登记，需用既有本地识别流程导入，或通过平台安装。

## 好友服务器离线

普通游戏启动无需登录启源好友账号，无需连接好友服务器，无需樱花账户。已安装完成、Java兼容、缓存Minecraft正版凭证仍有效时可启动。即便好友服务器关闭，也不会终止本地游戏。

首次登录/凭证过期续期需要微软网络；缺Java或依赖需下载。此功能没有增加离线用户名绕过正版认证。好友服务器与整个互联网断网是不同条件。

好友服务断线后会隐藏上次缓存的在线状态和开放世界；连接恢复后下次心跳恢复真实状态。添加好友、发布世界与点击好友加入仍需要服务连接。不同游戏版本及本地导入的原有限制见 LOCAL_IMPORT.md。

## 部署选择

服务端只传账号/好友/状态/世界元数据，游戏流量走SakuraFrp。小群可从1核1GB轻量云机试运行；无独立云机时也能放在常开电脑/NAS，通过Tailscale Serve提供HTTPS给同一私网成员，或使用已有服务器反向代理。具体命令、容量估算、限制与测试条件见服务端 DEPLOYMENT.md。没有自动部署或托管公共账号服务。

## 0.4.0 存储与本地联机

设置中的「本地存储位置」可选其他盘，预览后复制迁移。旧目录保留备份，确认新位置正常后自行清理。本地模组房主可以开放，好友选择已有实例、核对真实JAR后加入。客户端双方和好友服务端须0.4.0，具体步骤与限制见 STORAGE_AND_LOCAL_MULTIPLAYER.md。
